# Video Poker

A video poker game demonstrating React, TypeScript, and state management skills.

## Tech Stack

- React
- TypeScript
- Vite
- Zustand

## Features

- [ ] Jacks or Better video poker (9/6 paytable)
- [ ] Standard 52-card deck with shuffle
- [ ] Hold/discard logic
- [ ] Deal and draw logic
- [ ] Hand evaluation (Jacks or Better through Royal Flush)
- [ ] Credit/betting system with adjustable bet size
- [ ] Paytable display
- [ ] Round result feedback (win / no-win)
- [ ] "Out of coins" state when credits reach zero

## Get Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
